\begin{exercise}{75}
Show that $\Delta^0\to J$ is not inner-anodyne.

\begin{proof}
By Definition~1.3.25, $J$ is the nerve of the groupoid
with two objects and a unique morphism between each
ordered pair of objects.
Since $\Delta^0$ is an $\infty$-category,
Exercise~\ref{ex:51}(1) shows that either vertex
inclusion $\Delta^0\to J$ is an inner fibration.
It is not an isomorphism, as it maps one vertex into
a set of two vertices.
Exercise~\ref{ex:74} therefore shows that it is not
inner-anodyne.
\end{proof}
\end{exercise}
