\begin{exercise}{85}
Let $p\colon\mathcal C\to\mathcal D$ be an isofibration. Show that the set of all
monomorphisms $K\to L$ such that the induced map
\[
 \mathcal C^L\to\mathcal C^K\times_{\mathcal D^K}\mathcal D^L
\]
is again an isofibration is a saturated set.

\begin{proof}
For a monomorphism $i\colon K\to L$, write $u_i$ for the
map in the question.
It is an inner fibration by Theorem~1.3.37.
Its source is an $\infty$-category by Corollary~1.3.38,
and so is its target: the projection to $\mathcal D^L$
is a pullback of the inner fibration
$\mathcal C^K\to\mathcal D^K$, over an $\infty$-category.

Put $j\colon\{0\}\hookrightarrow J$ and fix the map
\[
 q\colon\mathcal C^J\longrightarrow
 \mathcal C\times_{\mathcal D}\mathcal D^J,
\]
whose components are evaluation at $0$ and application of $p$.
By Proposition~2.1.21, $u_i$ is an isofibration exactly
when it has the RLP with respect to $j$.
Lemma~1.3.30 identifies lifting problems for $j$ against
$u_i$ with lifting problems against $p$ for the map
\[
 (K\times J)\amalg_{K\times\{0\}}(L\times\{0\})
 \longrightarrow L\times J.
\]
By the same lemma and symmetry of products, these are
also precisely the lifting problems for $i$ against $q$.
In either description a filler is a compatible map
$L\times J\to\mathcal C$.

Hence the class in the question is
$\mathrm{Mono}\cap\chi_L(\{q\})$,
where $\mathrm{Mono}$ denotes the monomorphisms and
$\chi_L(\{q\})$ the maps having the LLP against $q$.
The latter class is saturated by Lemma~1.3.8.
The former is saturated by Exercise~\ref{ex:59} and
the same lemma.
Their intersection is saturated by Remark~1.3.7,
as required.
\end{proof}
\end{exercise}
