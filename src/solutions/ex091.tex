\begin{exercise}{91}
Let $F\colon\mathcal C\to\mathcal D$ be a functor between ordinary categories.
Show that the induced map on nerves is inner-anodyne if and only if $F$ is an
isomorphism.

\begin{proof}
Every map between ordinary nerves is an inner fibration:
fill a given inner horn in the source by Theorem~1.1.52;
its image equals the prescribed bottom simplex by uniqueness of the
filler in the target.
Hence Exercise~\ref{ex:74} shows that $\mathrm N(F)$ is inner-anodyne
exactly when it is an isomorphism.
The nerve functor is fully faithful by Corollary~1.2.20, so it
reflects isomorphisms; it also preserves them.
Thus $\mathrm N(F)$ is an isomorphism exactly when $F$ is.
\end{proof}
\end{exercise}
